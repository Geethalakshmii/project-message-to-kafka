# Kafka Message Producer with Spring Boot

This project demonstrates how to build a simple REST API using **Spring Boot** that sends JSON messages to an **Apache Kafka** topic. It uses **Docker Compose** to set up Kafka and Zookeeper locally.

---

## Features

- REST API to accept messages via HTTP POST
- Kafka Producer to send messages to a topic
- Docker setup for Kafka and Zookeeper
- JSON message serialization

---

## Technologies Used

- Java 21
- Spring Boot
- Apache Kafka
- Docker & Docker Compose
- Postman (for API testing)
- IntelliJ IDEA
